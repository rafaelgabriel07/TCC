\textbf{5. JUSTIFICATIVA}

Atualmente, a amplificação sonora se encontram presentes nos mais diversas atividades do nosso dia a dia. Seja em um
show, quando uma banda está se apresentando para uma plateia, em veículos autônomos quando deseja-se passar uma informação à quem está
conduzindo o veículo e até mesmo em aparelhos auditivos, melhorando a qualidade de vida de pessoas com deficiência auditiva.
Em todos esse casos há a necessidade de amplificar um sinal sonoro e, com isso, transmitir a informação desejada, mostrando-nos a importância
de dispostivos amplificadores de áudio.

como seu tamanho reduzido.

\textbf{6. OBJETIVO}

Neste projeto, pretende-se discutir o funcionamento de um amplificador de potência Classe D estéreo que seja capaz de reproduzir sinais sonoros com até 20 watts de 
potência RMS. Assim, pode-se estabelecer os seguintes objetivos específicos: (1) Projetar e simular o circuito do amplificador de potência classe D de maneira a garantir
que esteja dentro das normas IHF (\textit{Institute of High Fidelity}); (2) Projetar e simular o circuito de pré-amplificação, que conta com controle panorama, controle
de \textit{loudness} e controle de tonalidade; (3) Montar os circuitos em X PCB's (\textit{Printed Circuit Board}) de forma a garantir o pleno funcionamento; (4) Garantir
o funcionamento de todo o projeto a partir de testes em bancada em concordância com o que foi previsto nas simulações.

\vspace{0.4cm}

\textbf{7. METODOLOGIA}

Para concluir os objetivos, o projeto será feito da seguinte maneira. % Falo sobre a escolha dos ampops e do amplificador de potência?
Inicialmente será feito os cálculos para os circuitos de pré-amplificação, seguidos das simulações necessárias para validar os circuitos. Para o amplificador de potência,
o projeto iniciará diretamente na etapa de simulação, já que sera usado um IC \textit{Integrated Circuit}. Para as simulações, será usado o software PSpice for TI, simulador
da \textit{Texas instruments}.

Com os circuitos validados através das simulações, se dará início ao processo de confecção das PCB's. Para essa etapa, será utiliza o software \textit{Altium Designer}.

Após a montagem dos componentes na PCB, será feito os testes em bancada. Inicialmente sera feito os testes para cada um dos circuito e, após validar os resultados com os resultados das simulações,
será feito os testes no conjunto completo, para que possa-se verificar se está dentro das normas IHF. %Novamente entrando na questão de alta fidelidade. Verificar se isso realmente é possível
